ALPHAFIT — static site for Python http.server.

Logo: the user's uploaded transparent logo is stored locally as assets/logo-mark.svg (with the original transparent PNG alongside it). The HTML uses the local SVG, so the logo does not depend on Figma.

Important: the remaining photography in this version is still referenced from temporary Figma asset URLs. Those images can therefore load slowly or fail when Figma is unavailable. They need to be exported/downloaded locally from Figma to make the whole site fully offline and fast.

Run:
python -m http.server 8000
Then open http://localhost:8000
